Case study

One iframe. Any site.

Spoke Runner is a normal web game. The swap you can make at every station is the hosted SODAX swap widget in an <iframe>. No package to install, no backend, no keys. The whole integration lives in one file.

  1. Build the URL. Each planet locks the destination to its own gas token, so docking at Base means "get ETH on Base".
  2. Mount the frame. Keep the allow attribute so wallets work inside it.
  3. Listen. The widget posts sodax:swap statuses; the station lights up as your swap starts, submits and completes.
Embed for this station

The widget's messages carry a status only, no amounts or hashes, so a completed swap unlocks cosmetics here (a gold engine trail and a ring around the planet) and nothing of value.
